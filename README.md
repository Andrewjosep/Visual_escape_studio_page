# 🎮 Virtual Escapes Studio

A modern and visually engaging landing page for a virtual gaming and entertainment studio, built using **HTML5** and **CSS3**. The website features a fullscreen video background, responsive sections, and a clean user interface to provide an immersive browsing experience.

## ✨ Features

- 🎥 Fullscreen video background
- 🧭 Sticky navigation bar
- 🏠 Hero section with overlay content
- ℹ️ About Us section
- 🎯 Mission & Vision cards
- 🛠️ Services section
- 📱 Responsive layout
- 🎨 Modern and clean UI
- ⚡ Smooth hover effects and transitions
